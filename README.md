# 久遠寺邸の一夜 〜大正浪漫脱出奇譚〜

Three.js で作られた、大正時代の豪華な洋館(和洋折衷)を舞台にするブラウザ脱出ゲーム。
リビング・寝室・書斎の3部屋を巡り、屋敷の主が遺した13種の謎を解いて朝の庭へ脱出する。

- **絶対に詰まない**: 依存グラフの健全性+3段階ヒント+自動全行程クリアテスト+自動ソルバーによる詰み防止プロパティテストで構造的に保証
- **ギミックは全種別違い**: 探索 / 観察 / あぶり出し / 針合わせ / 鏡の実反射(鏡文字) / 計数 / ダイヤル錠 / 旋律再現 / 整列 / 消灯(夜光) / 回転機構 / アイテム結合 / 総合金庫
- **外部アセット不使用**: モデル・テクスチャ・音(オルゴール調BGM・全SE)はすべて手続き生成。バンドル約 190KB gzip

## 遊び方

```bash
npm install
npm run dev      # http://localhost:5173
```

- ドラッグ(スワイプ)で見回し、光る場所をクリック(タップ)して調べる
- アイテムは下部のインベントリで選択して対象に使う。⊕で3D拡大・結合
- 右上「ヒント」は3段階(3つ目はほぼ答え)。「おぼえがき」で入手した文書をいつでも再読
- オートセーブ。ゲームオーバー・時間制限なし

## 開発

```bash
npm test               # ユニット+統合(自動全行程クリア・詰み防止)

npm run build          # 型検査+本番ビルド
```

## アーキテクチャ

- `src/core` — 純粋関数のゲームロジック(不変データ・単一方向データフロー)。正解値は `constants.ts`、攻略手順は `solution.ts` に一元化し、美術・ロジック・テストが同じ値を参照する
- `src/scene` — Three.js(手続きテクスチャ・部屋・装置・実反射の鏡・ポストプロセス)
- `src/ui` — 素の DOM(縦書きの文書リーダー・ヒント・設定など)
- `src/audio` — Web Audio 全合成(FM オルゴール・ピアノ・環境音・3拍子のワルツ)
- `src/save` — zod 検証付きオートセーブ(破損・改竄は検出して安全に初期化)
