## 1. 作品概要

- 仮題: **『久遠寺邸の一夜 〜大正浪漫脱出奇譚〜』**(タイトルは変更可)
- 一晩だけの優しいミステリー。恐怖ではなく「懐かしさと好奇心」で牽引する脱出ゲーム。
- キャッチコピー案: *「この屋敷の謎はすべて、誰かの想い出でできている。」*

## 2. 物語

### 2.1 あらすじ

大正十年、春。あなたは亡き父の親友・久遠寺子爵から招待状を受け取り、洋館を訪れる。
応接間で紅茶をいただくうち、旅の疲れから深く眠り込んでしまう。
目覚めると屋敷は夜。人の気配はなく、扉には鍵。テーブルには子爵の手紙が残されていた。

> 「この屋敷の謎をすべて解き、玄関の鍵を手にした者に、約束の品を贈ろう」

屋敷に仕掛けられた謎は、子爵と、亡き妻・咲子と、あなたの父との想い出から作られたもの。
すべてを解き明かし、朝の庭へ——。

### 2.2 登場人物

| 人物 | 説明 |
|---|---|
| 主人公(プレイヤー) | 亡き父の子。性別・容姿は特定しない(一人称視点、独白のみ) |
| 久遠寺子爵(くおんじ ししゃく) | 屋敷の主。父の学生時代からの親友。無類の謎解き好き。手紙と仕掛けを通じてのみ登場し、エピローグで初めて姿を見せる |
| 咲子(さきこ) | 子爵の亡き妻。桜をこよなく愛した。日記・着物・宝石箱など寝室の品々の持ち主 |
| 父(悟) | 主人公の亡き父。子爵と「いつか互いの子に、とっておきの謎解きを贈ろう」と約束していた |

### 2.3 プロローグ(画面テキスト)

1. 大正十年、春。あなたは一通の招待状を受け取った。
2. 差出人は、亡き父の親友・久遠寺子爵。——「ぜひ屋敷へ。見せたいものがある」
3. 夕刻。通された応接間で紅茶をいただくうち、あなたは深い眠りに落ちてしまう。
4. 目を覚ますと、窓の外はすっかり夜。屋敷は静まり返り、人の気配がない。
5. そして、テーブルの上に一通の手紙が置かれていた。

→ 「子爵の手紙」(全文は 03 文書 §6)を表示し、探索開始。

### 2.4 エピローグ(脱出後)

1. 重い扉が開くと、東の空が白みはじめていた。
2. 朝露の庭に、子爵が立っている。「見事だった。約束の品を——」
3. 手渡された懐中時計は、父のものだった。蓋の裏には、若き日の父と子爵の写真。
   (※「思い出の写真」を結合済みの場合のみ一文追加: 「あなたが屋敷で見つけた、あの写真と同じものだった。」)
4. 「また遊びにおいで。この屋敷は、いつでも君を歓迎する」
5. 桜の花びらが、ひとひら。大正の朝の光の中で、あなたは深く一礼した。 —— 完 ——

### 2.5 トーン&マナー

- 優しい・ノスタルジック・上品。謎はすべて「子爵が客人のために用意した遊び」であり、悪意・危険・恐怖は一切存在しない。
- 夜の屋敷だが照明は常に暖かく、BGM は穏やか。ホラー的演出(急な音・影・追跡等)は禁止。

## 4. 屋敷の構造

### 4.1 フロアマップ(1階・遊戯範囲)

```
                          北
   ┌──────────────┬────────────────────┬──────────────┐
   │              │ 飾り棚  暖炉  柱時計 │  窓(月光)     │
   │   書  斎     │                    │   寝  室      │
   │  (6m×5m)   [扉A]   リビング       [扉B] (6m×5m)   │
   │              │   (8m×6m)          │              │
   │  本棚/机/    │  ソファ・ローテーブル │ ベッド/鏡台/  │
   │  地球儀/金庫  │  ピアノ  蓄音機      │ 箪笥/屏風     │
   └──────────────┤                    ├──────────────┘
                  │  ══[玄関扉(南)]══   │
                  └────────────────────┘
                          南
```

- リビングが中央のハブ。西の扉Aで書斎、東の扉Bで寝室に接続。玄関扉はリビング南壁。
- 扉A・Bは一度開錠したら開放のまま(再施錠しない)。行き来は自由。
- 天井高: リビング 3.8m(シャンデリア)、寝室・書斎 3.4m。

### 4.2 進行と部屋の開放

| 段階 | 行動範囲 | 目標 |
|---|---|---|
| Phase 1 | リビングのみ | 寝室の鍵を入手 |
| Phase 2 | リビング+寝室 | 書斎の鍵を入手(リビングに戻る謎あり) |
| Phase 3 | 全3部屋 | 金庫を開け、玄関の鍵を入手 |
| 脱出 | — | 玄関扉を開けてエンディング |

## 5. 部屋詳細

### 5.1 リビング(応接間)— 「火と時間の間」

洋館の顔。和洋折衷の豪華さを最も濃く見せる部屋。

| 配置 | 調度 | 役割 |
|---|---|---|
| 北壁中央 | 大理石の暖炉(薪組み済み) | ギミック(点火・あぶり出し) |
| 北壁東 | 柱時計(振り子停止・4時前で止まっている) | ギミック(針合わせ) |
| 北壁西 | 飾り棚(ガラス戸・真鍮の鍵穴) | ギミック(施錠棚)。オルゴール・マッチの収納元 |
| 西壁(扉Aの南) | アップライトピアノ | ギミック(旋律再現) |
| 東壁(扉Bの南) | 蓄音機(ラッパ型) | 装飾・調査フレーバー |
| 中央 | 臙脂のビロードソファ+ローテーブル+ペルシャ絨毯 | 開始地点。子爵の手紙 / クッションの鍵 |
| 南壁 | 玄関扉(両開き・重厚)+ステンドグラス欄間 | 最終脱出口 |
| 壁面 | 油彩の風景画(わずかに傾いている) | ギミック(絵画の裏) |
| 天井 | シャンデリア(電球色) | 照明 |

照明ムード: 暖炉(点火後)の橙+シャンデレアの電球色。窓外は藍色の夜 → エンディングで暁色。

### 5.2 寝室 — 「鏡と想い出の間」

咲子の記憶が残る、静かで柔らかな部屋。和の要素(屏風・着物)を最も強く出す。

| 配置 | 調度 | 役割 |
|---|---|---|
| 北東 | 真鍮フレームのベッド | 装飾・調査フレーバー |
| 東壁 | 鏡台(三面鏡ではなく一枚鏡) | ギミック(鏡文字を映す) |
| 西壁(扉Bの脇) | 金彩の屏風 | ギミック(鏡文字の本体・裏返しの文字) |
| 南壁 | 洋箪笥(観音開き) | ギミック(着物の花を数える) |
| ベッド脇 | サイドテーブル+咲子の日記+小ランプ | 手掛かり(自由閲覧) |
| 鏡台の上 | 宝石箱(花彫刻の3連ダイヤル) | ギミック(ダイヤル錠) |
| 北壁 | 窓(レースカーテン・月光) | 照明演出 |

照明ムード: 月光の青+ランプの橙のコントラスト。着物と屏風の金彩がほのかに光る。

### 5.3 書斎 — 「知と仕掛けの間」

子爵の遊び心が詰まった最後の部屋。仕掛けの密度が最も高い。

| 配置 | 調度 | 役割 |
|---|---|---|
| 西壁一面 | 造り付けの本棚 | ギミック(色順の整列・隠し棚) |
| 北側中央 | 両袖机+緑のバンカーズランプ+文具 | 引き出し(写真・書きかけの手紙) |
| 机の脇 | 地球儀(木製スタンド) | ギミック(回転機構・覚書) |
| 南壁 | 子爵の肖像画 | ギミック(裏の金庫) |
| 肖像画の裏 | 壁龕の金庫(鍵穴+3連ダイヤル) | 最終ギミック |
| 東壁(扉Aの脇) | 照明スイッチ(真鍮プレート) | ギミック(消灯 → 夜光文字) |
| 南東 | 安楽椅子+サイドテーブル | 装飾・調査フレーバー |
| 北壁 | 窓(木製ブラインド) | 照明演出 |

照明ムード: バンカーズランプの緑+電球色。消灯時は月明かりのみ+夜光塗料の淡い燐光(怖くならない明度を保つ)。

### 6.4 ヒント UI

- 右上「?」→ 現在挑戦可能な謎の一覧(未解決のみ)→ 謎を選ぶとヒント①を表示 → 「もっと見る」で②→③。
- ③は実質的な答え。回数無制限・ペナルティなし(リザルトの称号にのみ反映)。
- 表示文言は 03 文書に全謎ぶん定義済み。

### 6.5 おぼえがき(文書再読)

- 入手した文書(子爵の手紙 / あぶり出しの便箋 / 日記 / 覚書 / 最後の手紙 など)を一覧から再読できる。
- 柱時計の時刻・着物の花・オルゴールの旋律など環境側の手掛かりも、解いた後で現物を再確認できる状態を保つ(03 文書の詰み防止規則)。

### 6.6 セーブ・設定

- オートセーブのみ(状態変化ごとに保存)。タイトルの「つづきから」で復帰。
- 設定: BGM 音量 / SE 音量 / 画質(高・中・低)/ 視点感度 / ホットスポットマーカー / 文字表示速度。

## 7. アートディレクション

### 7.1 美術方針

「大正の洋館(和洋折衷)」。参照イメージ: 旧岩崎邸・鳩山会館・大正期の百貨店広告。
外部アセットを使わず、プリミティブ形状の組み合わせ+手続きテクスチャ+照明設計で成立させる。

**大正意匠チェックリスト(AC-07 対応)**
1. 寄木(ヘリンボーン)張りの床
2. 腰壁+ダマスク柄壁紙(ウィリアム・モリス風)
3. ステンドグラス欄間(玄関上部)
4. 真鍮の金物(取っ手・スイッチ・ベッドフレーム)
5. ビロード張りの猫脚家具
6. 電球色の照明(シャンデリア・バンカーズランプ)
7. 和の点景(屏風・着物・オルゴール台の組子)

### 7.2 カラーパレット(基準値・実装時に微調整可)

| 用途 | 色 | 目安 |
|---|---|---|
| 木部(飴色) | `#8b5a2b` / 濃部 `#4a3628` | 家具・床・建具 |
| ファブリック | 臙脂 `#8e354a` / 千歳緑 `#316745` | ソファ・カーテン・絨毯 |
| 壁紙 | 生成り `#e8dcc0` × 臙脂の柄 | ダマスク柄 |
| 金物 | 真鍮 `#c9a34e` | 取っ手・額縁・燭台 |
| 照明(電球) | `#ffb46b` | 室内全般 |
| 照明(月光) | `#9db4ff` | 窓からの差し込み |
| 照明(暖炉) | `#ff7f3f` | 揺らぎ付き |
| 照明(緑ランプ) | `#3ba776` | 書斎の机 |

### 7.3 ライティングとポストプロセス

- トーンマッピング: ACES Filmic。全体をやや暗めに保ち、電球色の光だまりで視線誘導する。
- 影: 主要光源 1〜2 灯のみシャドウマップ(画質設定で解像度切替)。
- ポストプロセス: 弱いブルーム+ビネット+ごく薄いフィルムグレイン(大正写真の質感)。明滅表現は使わない。
- 暖炉・ランプは強度をゆっくり揺らす(±10%程度、光過敏に配慮した低周波)。

## 8. サウンド設計(全て Web Audio API 合成)

### 8.1 BGM

| 曲 | 内容 |
|---|---|
| 探索テーマ | オルゴール風ワルツ(3/4拍子・AABA・約60秒ループ)。FM ベル音色+薄いリバーブ+蓄音機風ノイズを微量。音量は控えめ |
| エンディング | 探索テーマの長調変奏+朝の鳥の声(合成) |

### 8.2 SE(抜粋)

| SE | 用途 |
|---|---|
| かちゃ(施錠中)/ かちゃり(開錠) | 扉・棚・箱 |
| きらん | アイテム取得 |
| しゅっ / ぼっ / パチパチ(ループ) | マッチ・暖炉 |
| ボーン×4+機構音 | 柱時計のチャイム(正解演出) |
| ピアノ単音×8 / 不協和音 | ピアノ鍵盤 |
| オルゴールの旋律 | ミ・ソ・ラ・ド |
| かちかち / ごとん | 金庫ダイヤル・開扉 |
| かさ | 紙・文書 |
| ちりん | 謎解決の共通アクセント |
| 振り子・虫の音・夜風 | 環境音(音量小) |

### 8.3 アクセシビリティ

- 音が手掛かりになる箇所(オルゴール→ピアノ)は、必ず視覚情報(音名表示)を併設する。ミュートで完走可能(NFR-06)。
