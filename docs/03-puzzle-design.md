## 1. 設計原則(5箇条)

1. **多様性** — 同型のギミックを繰り返さない。使う頭の筋肉(探す・気づく・数える・聴く・並べる・思い出す)を毎回変える。
2. **公平性** — 答えは必ず屋敷の中の手掛かりから導ける。外部知識・言葉遊びの飛躍・ピクセルハントを要求しない。
3. **3手以内** — 1つの謎は「手掛かりを見る → 対応に気づく → 操作する」の3手以内で解ける粒度に保つ。
4. **詰み防止** — §9 の設計規則に全ギミックが従う。違反する仕様変更は不可。
5. **再挑戦自由** — 全ギミックは何度でも試せる。失敗によるペナルティ・状態悪化はない。

## 4. ギミック詳細仕様

書式 — **前提**: 挑戦可能になる条件 / **正解**: 進行する操作 / **誤操作**: 不正解時の挙動(全て無害) / **報酬**: 得られるもの / **ヒント**: ①場所 ②考え方 ③答え。

### L-1 ソファの下の鍵【探索】
- 前提: なし(開始直後。チュートリアルメッセージが「まずは周りを調べよう」と促す)
- 正解: ソファ中央のクッションを調べる
- 誤操作: 他の場所は調査フレーバー文を返すのみ
- 報酬: アイテム「真鍮の小鍵」
- ヒント: ①「まずは身の回りから。眠っていたソファが気になる」②「クッションの隙間に何か挟まっていないだろうか」③「ソファ中央のクッションを調べると『真鍮の小鍵』が見つかる」

### L-2 飾り棚【鍵の使用】
- 前提: なし(棚は最初から調査可。施錠中は「小さな鍵穴がある」)
- 正解: 「真鍮の小鍵」を選択して飾り棚に使う(鍵は役目を終えて消える。棚は開放のまま)
- 誤操作: 別アイテム使用時「合わないようだ」
- 報酬: 「マッチ箱」入手。「オルゴール」を発見(棚に置かれたまま。ねじ巻きが無く今は鳴らない、の説明文)
- ヒント: ①「北西の飾り棚に小さな鍵穴がある」②「ソファで見つけた小鍵が合いそうだ」③「真鍮の小鍵を飾り棚に使う。マッチ箱が手に入り、オルゴールが見つかる」

### L-3 傾いた絵画【観察】
- 前提: なし
- 正解: 暖炉上の風景画(常時わずかに傾いて描画)を調べる → 額が揺れ、裏から便箋が落ちる
- 誤操作: —(調べるだけで必ず成功)
- 報酬: アイテム「白紙の便箋」(拡大しても何も書かれていない)
- ヒント: ①「壁の絵画、どこか様子がおかしくないか」②「傾いた額の裏には、何か挟めそうだ」③「暖炉の上の絵画を調べると『白紙の便箋』が落ちてくる」

### L-4 あぶり出し【火・環境利用】
- 前提: 「マッチ箱」「白紙の便箋」所持
- 正解: (1)「マッチ箱」を暖炉に使う → 点火(以後燃え続ける) (2)「白紙の便箋」を点火済み暖炉に使う → あぶり出し演出
- 誤操作: 未点火の暖炉に便箋 →「火が入っていない」。点火後にマッチ再使用 →「もう火は点いている」
- 報酬: 便箋が「あぶり出しの便箋」に変化(おぼえがきで再読可)。文面: *「お茶会は、四時十分に始まる。止まった時をその刻へ戻せば、扉は開く。」*
- ヒント: ①「白紙の便箋は本当にただの白紙だろうか」②「古い手紙は、火であぶると文字が浮かぶことがある」③「マッチで暖炉に火を点け、便箋を暖炉に使う。時刻が浮かび上がる」

### L-5 柱時計【機構操作】
- 前提: なし(操作自体は最初から可能。知識ゲートのみ)
- 正解: 注視ビューで長針・短針を動かし「4時10分」に合わせる → チャイム → 下扉が開く
- 誤操作: 他の時刻では何も起きない(針は自由に動かせる)
- 報酬: 「寝室の鍵」。時計は 4:10 を指したまま残る(後の S-7 の手掛かり)
- ヒント: ①「便箋の時刻が手掛かり。この部屋で時を刻む物は?」②「柱時計の針は自由に動かせるようだ」③「柱時計を4時10分に合わせる。チャイムの後、下扉から寝室の鍵が出てくる」

### B-1 鏡の中の文字【光学・鏡文字】
- 前提: 寝室開放(「寝室の鍵」を扉Bに使用。鍵は消え、扉は開放のまま)
- 正解: 鏡台を調べる → 鏡に西壁の屏風が映り、裏返しだった文字が正しく読める
- 誤操作: 屏風を直接調べると「裏返しの文字が書かれている…読みにくい」(気づきの補助)
- 報酬: 知識: *「たんすの着物、花を数えよ」*(おぼえがきに記録)
- ヒント: ①「鏡台の鏡には、部屋の何かが映り込んでいる」②「屏風の読めない文字も、鏡越しなら…」③「鏡に映った屏風の文字は『箪笥の着物、花を数えよ』」

### B-2 着物の花【観察・計数】
- 前提: 寝室開放(箪笥は施錠なし)
- 正解: 箪笥を開け、掛けられた訪問着を注視ビューで見る。花は形で判別できる大きさ・配置(桜5輪・梅3輪・菊7輪。色覚に依存しない形状差)で描き分けられており、プレイヤーが実際に数えて把握する
- 誤操作: —
- 報酬: 知識: 桜5・梅3・菊7(調査時のテキストは花の種類を示すのみで数は明示しない。文書化もされず、絵を見て自分で数える)
- ヒント: ①「屏風の言葉に従って箪笥を見よう」②「着物には三種類の花。それぞれいくつ咲いている?」③「桜が5、梅が3、菊が7」

### B-3 宝石箱【ダイヤル錠(絵合わせ)】
- 前提: 寝室開放(ダイヤルは自由に回せる)
- 正解: 3連ダイヤル(各0〜9、上に桜・梅・菊の彫刻)を「5・3・7」に合わせて留め金をクリック
- 誤操作: 数字不一致なら「開かない」。ダイヤルはいつでも回し直せる
- 報酬: 「ねじ巻き」「写真(右半分)」
- ヒント: ①「鏡台の上の宝石箱、花の彫られたダイヤルが三つ」②「彫られた花と、着物の花の数を対応させる」③「桜5・梅3・菊7に合わせる。ねじ巻きと写真の右半分が手に入る」

### B-4 咲子の日記【読み物・伏線】
- 前提: 寝室開放(サイドテーブルの上。自由に読める・持ち出さない)
- 内容: 3項(全文は §6)。(1)書斎の本は「茜・山吹・若竹・瑠璃」の順に並べる主人の癖 → S-5 の手掛かり (2)父と子爵の謎解き遊びの想い出 → 物語 (3)咲子は桜が一番好き → S-7 の「咲子の花=桜」の裏付け
- ヒント対象外(いつでも読める)。S-5 のヒントから参照される

### L-6 オルゴール【音・旋律の取得】
- 前提: 「ねじ巻き」所持。リビングの飾り棚(開放済み)のオルゴールへ
- 正解: 「ねじ巻き」をオルゴールに使う → ねじ巻きは装着され(インベントリから消える)、以後何度でも再生可能
- 演出: 旋律「ミ・ソ・ラ・ド」(E4-G4-A4-C5)を再生。同時に音名を画面に表示。蓋の裏にも「ミ ソ ラ ド」の刻印(無音環境の保険)
- 報酬: 知識: 旋律ミ・ソ・ラ・ド(4音)
- ヒント: ①「ねじ巻きが合う品は、この屋敷のどこかで見た」②「飾り棚のオルゴールに使ってみよう」③「オルゴールにねじ巻きを使うと『ミ・ソ・ラ・ド』の旋律が流れる」

### L-7 ピアノ【旋律再現】
- 前提: なし(鍵盤は最初から弾ける。知識ゲートのみ)
- 正解: 注視ビューの鍵盤(ドレミファソラシド8鍵・各鍵に音名表示)で「ミ→ソ→ラ→ド(高)」の順に弾く
- 誤操作: 4音入力ごとに判定。不一致なら不協和音が短く鳴り入力リセット(ペナルティなし)
- 報酬: 鍵盤下の隠し引き出しが開き「書斎の鍵」
- ヒント: ①「オルゴールの旋律には続きの遊びがある。この屋敷で音を奏でる物は?」②「ピアノで同じ旋律を弾いてみよう。音名はオルゴールの蓋の裏にも」③「ピアノで ミ・ソ・ラ・ド の順に弾く。隠し引き出しから書斎の鍵が手に入る」

### S-1 机の引き出し【探索】
- 前提: 書斎開放(「書斎の鍵」を扉Aに使用。鍵は消え、扉は開放のまま)
- 正解: 机の引き出しを開ける(施錠なし)
- 報酬: 「写真(左半分)」、文書「書きかけの手紙」(物語フレーバー・§6)
- ヒント: ①「書斎の机、引き出しは開くだろうか」②③(①で十分なため同文言の詳細化のみ)

### S-2 思い出の写真【アイテム結合・任意】
- 前提: 「写真(右半分)」「写真(左半分)」所持
- 正解: 拡大ビューで2枚を結合 → 「思い出の写真」に(裏書きは §6)
- 効果: エピローグに追加の一文(02文書 §2.4)。**進行必須ではない**(未結合でも脱出可能)
- ヒント: ①「写真は半分に破れている。もう片方はどこかに」②「持ち物の拡大画面で組み合わせられそうだ」③「写真(右)と写真(左)を結合する」

### S-3 夜光の文字【環境状態(消灯)】
- 前提: 書斎開放
- 正解: 扉A脇の照明スイッチを操作 → 消灯(月明かりの薄明+燐光)。机の上の壁に夜光塗料の文字が浮かぶ。再点灯も自由
- 誤操作: —(トグルのみ。消灯中も全操作可能で、点灯に戻せば元通り)
- 報酬: 知識: *「地球儀を回せ。日出づる国を正面に。」*(壁面の演出のみ。おぼえがきには記録しない)
- ヒント: ①「書斎の入口脇に照明のスイッチがある」②「暗くしないと見えないものもある」③「消灯すると机の上の壁に『地球儀を回せ。日出づる国を正面に』と浮かぶ」

### S-4 地球儀【回転機構】
- 前提: なし(回転は自由。知識ゲートのみ)
- 正解: 注視ビューで地球儀をドラッグ回転し、日本(赤い印+「日本」ラベル)をほぼ正面(±15°)に向けて留め金をクリック → 上半球が開く
- 誤操作: 向きが違えば「留め金が動かない」
- 報酬: 文書「覚書」(§6): 金庫の場所(肖像の裏)と、3つの数の意味
- ヒント: ①「夜光の文字は地球儀のことを指している」②「『日出づる国』は日本。回して正面に向けよう」③「日本を正面にして留め金をクリック。中から覚書が出てくる」

### S-5 本棚の色順【整列】
- 前提: 書斎開放(操作は自由。知識ゲートのみ)
- 正解: 本棚の特別な4冊(背表紙が茜=赤/山吹=黄/若竹=緑/瑠璃=青。**色名が背表紙に印字**されており色覚に依存しない)を、専用の4スロットに左から「茜・山吹・若竹・瑠璃」の順で並べ替える(クリックで取り出し/差し込みの入れ替え式)
- 誤操作: 順不同なら何も起きない。何度でも並べ替え可
- 報酬: 隠し棚が開き「金庫の鍵」
- ヒント: ①「日記に、本の並びについての癖が書かれていた」②「茜・山吹・若竹・瑠璃——すべて色の名前だ」③「4冊を左から 茜(赤)・山吹(黄)・若竹(緑)・瑠璃(青) の順に並べる。隠し棚から金庫の鍵が出る」

### S-6 肖像画の裏【観察】
- 前提: なし(最初から動かせる。額の右下がわずかに浮いた描画で示唆)
- 正解: 肖像画を調べる → 蝶番で開き、壁龕の金庫が現れる
- 報酬: 金庫の発見(FV-16 へ)
- ヒント: ①「覚書によれば、金庫は『わが肖像の裏』」②「南壁の肖像画、額の右下が浮いている」③「肖像画を調べると開き、金庫が現れる」

### S-7 金庫【総合・二重ロック】
- 前提: 金庫の発見(S-6)。開錠には「金庫の鍵」(S-5)+正しいダイヤル
- 正解: (1)「金庫の鍵」を鍵穴に使う (2)3連ダイヤルを「4・5・4」に合わせる → 開扉
  - 4 = 柱時計が指す「時」(4時10分の 4)
  - 5 = 咲子が最も愛した花=桜が着物に咲く数(5)
  - 6 ではなく 4 = 二人の旋律「ミ・ソ・ラ・ド」の音の数(4)
- 誤操作: 鍵なしでダイヤルだけ合わせても「鍵穴が塞がっている」。数字違いは「開かない」
- 検算可能性: 柱時計は 4:10 のまま・着物は再確認可・オルゴールは再生可 → 3つの数は**いつでも現物から再導出できる**(メモ不要)
- 報酬: 「玄関の鍵」「懐中時計」(拡大鑑賞可)、文書「最後の手紙」(§6)
- ヒント: ①「覚書の三つの数。答えはすべて、屋敷で解いた謎の中にある」②「柱時計の『時』・着物の桜の数・旋律の音の数」③「金庫の鍵を差し、ダイヤルを 4・5・4 に合わせる」

### L-8 玄関扉【鍵の使用・脱出】
- 前提: 「玄関の鍵」所持
- 正解: リビング南の玄関扉に「玄関の鍵」を使う → EV-08(エンディングへ)
- 誤操作: 鍵なしで調べると「重厚な錠が下りている。屋敷のどこかに鍵があるはずだ」
- ヒント: ①「金庫で手に入れた鍵の使い道は一つ」②③「玄関扉に玄関の鍵を使えば脱出」

## 7. 依存関係グラフ(必須経路の DAG)

`──▶` は手掛かり・アイテムの依存、`══▶` は進行ゲート(鍵・扉)の突破。

```
【Phase 1: リビング】
 L-1 ソファ ──▶ 真鍮の小鍵 ──▶ L-2 飾り棚 ──▶ マッチ箱 ─┐
                                    │                  ├─▶ L-4 あぶり出し(四時十分)
 L-3 傾いた絵画 ──▶ 白紙の便箋 ──────┼──────────────────┘        │
                                    └▶ オルゴール発見(要ねじ巻き)   ▼
                                                        L-5 柱時計 ══▶ 寝室の鍵

【Phase 2: 寝室 ⇄ リビング】(寝室の鍵 ══▶ 扉B開放)
 B-1 鏡文字 ──▶ B-2 着物の花(5・3・7) ──▶ B-3 宝石箱 ══▶ ねじ巻き+写真(右)
 B-4 日記(自由閲覧) ──▶ 本の色順の知識 ……(Phase 3 の S-5 へ)
 ねじ巻き ──▶ L-6 オルゴール(ミソラド) ──▶ L-7 ピアノ ══▶ 書斎の鍵

【Phase 3: 書斎】(書斎の鍵 ══▶ 扉A開放)
 B-4 の知識 ──▶ S-5 本棚の色順 ══▶ 金庫の鍵
 S-3 消灯(夜光文字) ──▶ S-4 地球儀 ══▶ 覚書(場所+数の意味)
 S-1 机 ──▶ 写真(左) ─(任意)─▶ S-2 結合「思い出の写真」
 覚書 ──▶ S-6 肖像画 ──▶ 金庫発見
 金庫の鍵 + 検算(時計4/桜5/旋律4) ──▶ S-7 金庫 ══▶ 玄関の鍵+懐中時計+最後の手紙

【脱出】
 玄関の鍵 ──▶ L-8 玄関扉 ══▶ ENDING
```

**健全性(トポロジカル順の証明)**: 各 Phase で新たに必要となる手掛かり・アイテムは、すべてその時点で開放済みの領域にのみ存在する(上表の通り循環依存なし)。ゲートを跨いで「先の部屋の物」が必要になる箇所は存在しない。よって、到達可能な任意の状態から脱出まで必ず到達できる。

**知識ゲートの扱い**: 柱時計・ピアノ・地球儀・本棚・宝石箱・金庫のダイヤル等は「操作自体は常時可能・正解を知っているかだけが障壁」。手掛かり未読でも正解操作すれば進行する(偶然の先回りは許容。詰みは発生しない)。

## 9. 詰み防止設計規則(全実装が従うこと)

| ID | 規則 |
|---|---|
| R-1 | 扉・棚・金庫など一度開いたものは再施錠されない |
| R-2 | 必須アイテム・手掛かりは、必要になる時点で必ず到達可能な場所にある(§7 の DAG を変更する場合は再証明する) |
| R-3 | アイテムは「正解の使用」でのみ消費される。誤った対象に使っても消えない・減らない |
| R-4 | 時間制限・失敗回数制限・ランダム性・リアルタイム反射要素を設けない |
| R-5 | 全ギミックは何度でも再挑戦できる。途中状態(ダイヤル位置など)はいつでも変更可能 |
| R-6 | 解いた後も手掛かりの現物は再確認できる(時計は 4:10 のまま・オルゴール再生自由・文書はおぼえがきに残る)。メモを取らなくても最終謎まで解ける |
| R-7 | 全ギミックに3段階ヒントを用意し、最終段は答えそのものとする(=論理的に詰み不可能) |
| R-8 | オートセーブは常時の状態保存であり、進行を壊すチェックポイント巻き戻しを持たない。破損時は検証で検出し安全に初期化する |
| R-9 | 音・色が手掛かりの謎には必ず代替表現(音名表示・色名印字・形状差)を併設する |

### 検証との対応(受け入れ基準 AC-01〜03 の実現手段)

| 規則 | 検証手段 |
|---|---|
| R-2(経路健全性) | §8 の攻略チャートをそのまま Action 列にした**自動全行程クリアテスト**(reducer 検証+E2E) |
| R-1 / R-3 / R-5 | reducer のプロパティテスト(誤使用で状態不変・開放状態の不変性・再挑戦可能性) |
| R-7 | 全ギミック ID にヒント3件が定義されていることの網羅テスト |
| R-8 | セーブデータの往復(save→load)同値テスト+破損データ投入テスト |
| R-9 | 仕様レビュー(本書チェックリスト)+E2E のミュート実行 |
